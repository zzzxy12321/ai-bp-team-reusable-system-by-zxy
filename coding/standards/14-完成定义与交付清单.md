# Definition of Done 与交付清单

## ✅ 功能完成

- 验收标准全部满足
- 成功、失败、空、权限和并发路径已处理
- 页面和接口状态明确
- 高风险动作有人工确认
- 数据对象和流程状态一致

## 🧱 工程完成

- 使用冻结技术栈
- 遵守模块和分层边界
- 无未评审依赖
- 无硬编码密钥和地址
- API 契约和前端类型一致
- 数据库迁移和回滚方案明确
- 无临时调试代码

## 🔐 安全完成

- 身份和权限校验
- 数据范围校验
- 字段脱敏
- 审计完整
- 日志无敏感信息
- CSRF/XSS/注入防护
- 外部写回有幂等和补偿

## 🧪 测试完成

- 单元测试
- 集成测试
- API 契约测试
- 关键流程测试
- 前端组件或页面测试
- 桌面与移动端 E2E
- 权限越界测试
- 并发和幂等测试
- 数据库迁移测试
- 离线构建测试
- 回滚和恢复演练

## 📚 文档完成

- 功能地图更新
- 模块 README 更新
- OpenAPI 更新
- 数据库文档更新
- ADR（有必要时）
- README、部署和运维说明更新
- `task_plan.md`、`findings.md`、`progress.md` 更新

## 🚀 发布完成

- 版本号和提交号明确
- 发布包完整
- 依赖锁定
- 离线包可恢复
- 数据库备份
- 健康检查
- 烟雾测试
- 回滚演练
- 业务验收
- 部署记录

## 📦 甲方交接完成

- 仓库可以完整克隆
- `README` 说明构建、配置、部署和端口
- 离线依赖说明
- 数据库迁移说明
- 服务安装说明
- 备份恢复说明
- 运维手册
- 测试命令和证据
- 已知限制
- 联系人/责任角色

## 🚫 不得标记完成的情况

- 只是页面能打开
- 只是 API 返回 200
- 只是本机能运行
- 只测了一条成功路径
- 数据库迁移没有验证
- 依赖未锁定
- 文档和功能地图未更新
- 存在未说明的 Mock
- 修 Bug 没有回归测试
- 无回滚方案
- 还有高风险未解决问题

## 🏁 最终判定

只有同时满足功能、工程、安全、测试、文档、发布和交接要求，任务才能标记为完成。
