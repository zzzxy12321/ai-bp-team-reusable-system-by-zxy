# 测试与回归规范

## 🎯 目标

测试的目标不是追求覆盖率数字，而是证明：

- 业务规则正确
- 权限边界正确
- 数据一致性正确
- 接口契约一致
- 前端关键路径可用
- 修改没有破坏相关功能
- 离线环境和部署可复现

## 🧱 测试层级

| 层级 | 测试内容 | 工具方向 |
|---|---|---|
| Domain 单元测试 | 状态、规则、值对象、领域事件 | xUnit + Shouldly |
| Application 测试 | 用例、权限、事务、幂等、并发 | xUnit + Mock |
| Infrastructure 集成测试 | EF Core、SQL Server、约束、迁移 | 测试实例/测试库 |
| API 契约测试 | 路径、请求、响应、错误码、权限 | ASP.NET Core TestServer |
| Workflow 测试 | Elsa 流程节点、条件、退回、版本 | 集成测试 |
| Vue 组件测试 | props、emits、状态、权限、错误 | Vitest + Testing Library |
| 浏览器 E2E | 发起、待办、审批、对象、审计、移动端 | Playwright |
| 离线构建测试 | restore、npm ci、build、publish | 断网环境脚本 |
| 部署恢复测试 | 部署、健康检查、回滚、备份恢复 | PowerShell + 测试实例 |

## 🧪 测试准入

任何功能开始前必须有：

- 验收场景
- 成功路径
- 失败路径
- 权限路径
- 数据一致性点
- 回归范围

没有验收场景的任务不得直接编码。

## 🔁 回归矩阵

每个功能在功能地图中登记：

| 功能 ID | 主要测试 | 邻近测试 | 高风险回归 |
|---|---|---|---|
| WF-001 | 流程发起、任务生成 | 对象状态、审计 | 权限、幂等、版本 |
| WF-002 | 审批推进 | 下一任务、状态 | 并发、退回 |
| OBJ-001 | 对象创建与版本 | 流程引用 | 权限、字段脱敏 |
| API-001 | 请求响应契约 | 前端 API client | 错误码、兼容 |
| SEC-001 | 未登录拒绝 | 菜单隐藏 | 数据范围、日志 |
| DEP-001 | 健康检查 | 静态资源 | 回滚、离线依赖 |

## 🐞 Bug 修复测试规则

1. 先复现 Bug。
2. 先增加失败测试或可重复验证脚本。
3. 修复根因。
4. 测试从失败变为通过。
5. 运行相关邻近测试。
6. 增加回归用例。
7. 记录影响范围和证据。

无法自动化的场景必须提供可重复手工验证步骤和截图/日志证据。

## 🔐 权限测试

至少覆盖：

- 未登录
- 无菜单权限
- 有菜单但无 API 权限
- 有接口权限但无数据范围
- 字段脱敏
- 数字员工跨范围访问
- 高风险动作缺少确认

## ✍️ 写接口测试

至少覆盖：

- 首次成功
- 同幂等键重放
- 同键异内容冲突
- 重复点击
- 并发更新
- 事务失败回滚
- 审计和 Outbox 是否同步

## 🌐 前端测试

每个页面至少覆盖：

- loading
- empty
- success
- validation error
- permission denied
- network/server error

关键页面必须做桌面和 390px 移动端浏览器验证。

## 🧬 数据库测试

- 新库完整迁移
- 上一版本库升级
- 约束、唯一键和外键
- 备份恢复
- 大表查询计划
- 并发和锁冲突

## 🚀 离线与部署测试

发布前至少验证：

1. 外网环境 restore 并生成离线依赖。
2. 断网环境 `dotnet restore/build/publish`。
3. 断网环境 `npm ci/build`。
4. 数据库迁移。
5. 部署脚本。
6. 健康检查。
7. 回滚。
8. 备份恢复。

## 🚦 CI 门禁

合并前必须通过：

- 编译
- 单元测试
- 集成测试
- 格式检查
- 静态分析
- 密钥扫描
- 依赖漏洞检查
- 数据库迁移检查
- 前端类型检查
- 前端构建
- 关键 E2E

任何跳过项必须记录原因、风险和补做时间。

## 🧾 测试证据

完成报告必须包含：

- 执行命令
- 测试环境
- 数据版本
- 通过数量
- 失败数量
- 跳过数量
- 截图或 JSON 报告
- 已知未覆盖风险

不得用“测试通过”四个字代替证据。

## 🚫 测试反模式

- 修改测试以掩盖代码错误
- 删除失败测试
- 只测成功路径
- 只测接口不测权限
- 只测桌面不测移动
- 使用生产数据
- 没有复现就修 Bug
- 覆盖率很高但关键场景空白
