# 目标模式提示词：会话恢复与交接

你正在恢复一个中断的 AIDT 开发任务。不要凭记忆重做，不要从头扫描全仓库。

## 第一步：读取

1. `AGENTS.md`
2. `docs/001-产品PRD/00-项目目标.md`
3. `docs/001-产品PRD/01-需求基线.md`
4. `docs/001-产品PRD/02-技术栈与架构.md`
5. `docs/001-产品PRD/03-计划方案.md`
5. `standards/00-AI工程宪法.md`
6. `standards/01-上下文阅读与恢复.md`
7. `task_plan.md`
8. `findings.md`
9. `progress.md`
10. 当前任务的变更计划或会话交接
11. `docs/project/FEATURE_MAP.md`

然后检查：

- Git 状态
- Git diff
- 未跟踪文件
- 最近测试结果
- 当前运行服务

## 第二步：恢复状态

填写：

```markdown
## 当前目标

## 已完成

## 未完成

## 实际修改文件

## 测试结果

## 阻塞点

## 下一步最小动作

## 禁止重复的操作
```

## 第三步：核对

- 是否使用冻结技术栈
- 是否出现未登记文件
- 是否有临时目录
- 是否有未提交测试
- 是否有数据库迁移
- 是否更新功能地图

## 第四步：继续

只执行“下一步最小动作”。完成并验证后再进入下一项。

如果恢复信息冲突，先列出冲突并以磁盘文件和 Git 实际状态为准，不得猜测。
