# 目标模式提示词：重构

你要对 AIDT 的指定范围进行重构。重构不得改变外部行为。

## 输入

- 重构范围：
- 重构目标：
- 明确不改变的契约：
- 现有测试：

## 开始前

读取：

- `AGENTS.md`
- 项目目标
- 架构与模块边界
- 相关开发规范
- 功能地图
- 模块 README
- 相关 API、迁移和测试

## 规则

1. 先确认测试基线。
2. 只处理一个边界：模块、分层、数据结构、前端组件或接口。
3. 不混入新功能。
4. 不顺便升级依赖。
5. 不改变 API、数据库和用户行为，除非另有明确任务。
6. 每次小步修改后运行相关测试。
7. 修改模块边界时写 ADR。

## 审查

- 依赖方向
- 循环依赖
- 数据所有权
- 公共契约
- 性能和日志
- 测试覆盖

## 输出

1. 重构前后行为等价证据
2. 代码边界变化
3. 测试结果
4. 文档和 ADR
5. 回滚方式
6. 未解决风险
