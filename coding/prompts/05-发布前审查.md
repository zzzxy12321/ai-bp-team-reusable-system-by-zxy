# 目标模式提示词：发布前审查

你要对 AIDT 的待发布版本执行发布前审查。默认只读检查，不直接部署生产。

## 开始前

读取：

- `AGENTS.md`
- 项目目标、需求、技术栈
- 完成定义
- Git 评审规范
- 构建部署回滚规范
- 测试与回归规范
- 功能地图
- 最近变更和 `progress.md`

## 审查范围

### 代码

- 分层和模块边界
- 未评审依赖
- 硬编码配置和密钥
- 临时调试代码
- 数据库迁移

### 契约

- OpenAPI
- 前端 API 类型
- 错误码
- 幂等和并发
- 向后兼容

### 安全

- 登录
- 权限和数据范围
- 审计
- 敏感日志
- 上传和导出
- AI 数据边界

### 测试

- 单元
- 集成
- API
- E2E
- 权限
- 并发
- 数据库迁移
- 离线构建

### 部署

- 版本号
- 发布包
- 依赖锁定
- 离线包
- 配置差异
- 数据库备份
- 健康检查
- 烟雾测试
- 回滚

## 输出

| 项目 | 结果 | 证据 | 风险 | 是否阻断 |
|---|---|---|---|---|

最后给出：

- Go
- Conditional Go
- No-Go

不得用代码已提交代替发布就绪。
