# Vibecoding 提示词索引

## 📌 使用原则

1. 选择与任务类型对应的提示词。
2. 不要用“大而全”的提示词同时完成功能、重构、数据库和发布。
3. 每个提示词都必须先读取 `AGENTS.md` 和项目规范。
4. 目标模式任务结束前必须运行测试并更新计划文件。

## 🚨 通用硬规则

- 不读全仓库，先读功能地图和模块索引。
- 没有影响分析，不进行大范围修改。
- 不在同一任务混合功能、重构、升级和部署。
- 不修测试掩盖代码错误。
- 不把 Mock 说成真实集成。
- 不把计划或推测说成已完成。
